# Resource sources and verification

Lunivo is an independent directory. It is not affiliated with CBSE, NCERT, the Ministry of Education, or any listed service.

## Original directory

The original CBSE Library external-links menu supplied as the project's starting reference:
https://cbseacademic.nic.in/library/index.html

Legacy names transcribed from that page include CBSE Academic, NCERT, MHRD, e-GyanKosh, Digital Library of India, National Science Digital Library, CBSE News Digest, CENBOSEC, Universal Digital Library, International Children's Digital Library, US Link, JSTOR, Internet Archive, Khan Academy and MIT OpenCourseWare.

## Manual review required

The following legacy or ambiguous records are marked in the dataset as needing verification:

- CBSE News Digest — the old directory label does not identify a specific current destination.
- Digital Library of India — legacy destination and successor status require confirmation.
- National Science Digital Library — the current catalogue URL is a related institutional portal, not a confirmed NSDL replacement.
- International Children's Digital Library — current availability should be checked.
- US Link — the source label is ambiguous; the current destination is provisional.
- Universal Digital Library — the current catalogue URL points to Internet Archive as a related archive, not a verified same service.
- National Repository of Open Educational Resources (NROER) — portal availability should be checked.

A URL appearing in an old directory or institutional list does not establish current availability, official status, access conditions, licensing, or endorsement. Check each target site's current identity, URL, terms, availability and safety before promotion. Access labels in Lunivo are indicative and may vary by item, account or institution.
