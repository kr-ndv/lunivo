# Resource sources and verification

Lunivo is an independent directory. It is not affiliated with CBSE, NCERT, the Ministry of Education, universities, publishers or any listed service.

## How to read source status

A source review date records when the reference was checked during curation. It is not a live uptime monitor, a guarantee that a particular page will load for every visitor, or a warranty about access, eligibility, copyright or licensing. A catalogue entry is an editorial summary, not an endorsement.

Access labels are deliberately qualified. For example, free search does not mean every full-text item is free, and an open textbook's licence does not describe every resource hosted by the same platform. Visitors should check the provider's current terms and item-level rights.

## Manual review required

The following seven legacy records remain marked **Needs review** in the dataset:

- **CBSE News Digest:** the old directory label does not identify a specific current destination. The CBSE academic portal is only a starting point.
- **Digital Library of India:** legacy destination and successor status require confirmation.
- **National Science Digital Library:** the current catalogue URL is a related CSIR-NIScPR institutional portal, not a confirmed NSDL replacement.
- **International Children's Digital Library:** current service availability and destination should be checked.
- **US Link:** the source label is ambiguous; the current USA.gov destination is provisional and may not be what the legacy label intended.
- **Universal Digital Library:** the current catalogue URL points to Internet Archive as a related archive, not a verified continuation of the same service.
- **National Repository of Open Educational Resources (NROER):** portal availability requires confirmation.

The e-ShodhSindhu portal was not added as an active catalogue record because its official portal displayed a maintenance notice during this review. Revisit it after the service's current status is confirmed: https://ess.inflibnet.ac.in/.

A URL appearing in an old directory or institutional list does not establish current availability, official status, access conditions, licensing or endorsement. Confirm the intended service, current URL and terms before removing a review flag.
