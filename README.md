# Lunivo

**Discover beyond boundaries.** An independent directory for educational websites, digital libraries, research platforms and learning resources.

## v1.0
A static, dependency-light website built with vanilla HTML, CSS and JavaScript.

- Responsive single-page experience
- Dark/light theme with locally remembered preference
- Search across resource names, descriptions and metadata
- Category filters and alphabetical sorting
- Resource detail modal and external-link disclosure
- Featured collections and additional resources
- No account, backend, build step or runtime package required

## Run locally
Open `index.html` in a modern browser. Google Fonts load from the internet; all application functionality is client-side.

## Deploy
Suitable for GitHub Pages or any static web host. For GitHub Pages, choose **Deploy from a branch**, select `main` and `/(root)` in repository Settings → Pages.

## Resource sourcing and editorial policy
The starting catalogue combines links from the original [CBSE Library external-links directory](https://cbseacademic.nic.in/library/index.html) with institutional resource lists and currently maintained official education platforms:
- [KVS RO Ranchi — Digital Resources](https://roranchi.kvs.gov.in/en/digital-resources/)
- [CSIR-CRRI — Open Access e-Resources](https://crridom.gov.in/en/open-access-e-resources)
- [SBSGCH Library — E-Resources](https://sbsgch.ac.in/e-resources.html)
- [CBSE OER Appendix 2025](https://cdnbbsr.s3waas.gov.in/s3kv01c185440ab7ba6b1904b078bb4e0f/uploads/2025/07/2025072977.pdf)

Lunivo is independent and is not affiliated with CBSE, NCERT or any listed service. Links and short descriptions are provided for discovery; destinations remain controlled by their operators. Old/ambiguous records are marked "Needs verification". In particular, the historical Digital Library of India, National Science Digital Library, Universal Digital Library, International Children's Digital Library and "US Link" entries require human review before being promoted as current official destinations. Access labels are indicative and may vary by item, account or institution.

## Current limitations
- Catalogue is stored in the HTML file; no CMS/admin dashboard.
- Recently added is a curated discovery section, not a timestamped activity feed.
- Resource submissions and broken-link reporting are not yet connected to a backend.
- Replace the example contact address before launch.
- Verify all legacy URLs, logos, terms and descriptions before public promotion.

## Brand
Lunivo's selected identity is the Open Page mark, Space Grotesk / Inter typography and teal/mint palette.
