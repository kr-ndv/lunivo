# Lunivo

**Discover beyond boundaries.** An independent directory for educational websites, digital libraries, research platforms and learning resources.

## v1.1

A static, dependency-light website built with vanilla HTML, CSS and JavaScript.

- Responsive single-page discovery experience
- Dark/light theme with locally remembered preference
- Search across resource names, descriptions and metadata
- Category filters and alphabetical sorting
- Three curated collection pathways
- Resource detail dialog with source provenance and external-link disclosure
- Keyboard focus handling for the detail dialog
- Brand favicon and social-sharing metadata
- No account, backend, build step or runtime package required

## Run locally

Open `index.html` in a modern browser. Google Fonts load from the internet; all application functionality is client-side.

## Deploy

Suitable for GitHub Pages or any static web host. To publish with GitHub Pages, open repository Settings → Pages, choose **Deploy from a branch**, then select `main` and `/(root)`.

## Resource sourcing and editorial policy

The starting catalogue combines links from the original [CBSE Library external-links directory](https://cbseacademic.nic.in/library/index.html) with institutional resource lists and current platform destinations. See [SOURCES.md](SOURCES.md) for the source register and verification notes.

Lunivo is independent and is not affiliated with CBSE, NCERT or any listed service. Links and short descriptions are provided for discovery; destinations remain controlled by their operators. Old or ambiguous records are marked **Needs verification** in the interface. A historical listing does not establish current availability, official status, access conditions, licensing or endorsement. Access labels are indicative and may vary by item, account or institution.

## Before public launch

- Verify each destination, especially records marked **Needs verification** in the interface and `SOURCES.md`.
- Test the experience in current desktop and mobile browsers, including keyboard-only navigation and screen-reader labels.
- Enable GitHub Pages or connect another static host; hosting has not been enabled by this repository change.
- Resource suggestions and broken-link reports currently open GitHub Issues. There is no submission backend or admin dashboard.
- The catalogue and collection membership are maintained in `index.html`; the “Across the knowledge landscape” row is a curated selection, not a live activity feed.
